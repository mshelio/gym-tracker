# Training techniques

In an active workout, open **Set technique & rest** below a set.

- **Add drop set** inserts a new set after it with a suggested 20% lighter weight. The preceding set's rest becomes zero. Adjust the suggestion to available equipment; actual reps are left blank.
- **Add reverse drop set** inserts a new set with a suggested 10% heavier weight. Rest follows the current defaults unless overridden. Actual reps are left blank.
- **To failure** records a failure set and zero reps in reserve when completed/saved. Enter actual reps; checking the option does not complete the set or start rest.
- **Rest after this set** overrides the other rest choices. Blank uses defaults; zero means no timer.

Open **Rest between exercises & supersets** to set exercise-transition, superset-transition, and round-rest durations (0–600 seconds). Between ordinary sets, the existing exercise/session rest default still applies. Completing an exercise uses the exercise-transition duration. Completing the entire workout stops rest.

In **Exercise options**, pair an exercise with the next exercise. Pairs cannot overlap. Each exercise retains its own weights, reps, and sets. Completing one set opens its partner; once both sets at that position are complete, round rest starts. Rounds use set positions; if one exercise has extra sets, those remaining positions have no partner. Pairing is available for adjacent planned exercises, including exercises in custom workout templates.

Drop and reverse-drop sets contribute to volume but are excluded from hard-set counts and automatic progression targets, consistent with existing drop-set behavior. Technique labels and per-set rest are shown in saved history. Pairing/rest settings and failure fields are optional backup fields; older backups still load. These settings apply to the current workout draft, not automatically to future sessions.
