# Gym Tracker v1.3.0 — draft release notes

**Status: draft only. Do not tag or publish without explicit authorization.**

## Highlights
- Detailed front and back anatomical illustrations using 89 licensed SVG path regions from [vulovix/body-muscles](https://github.com/vulovix/body-muscles) (Apache-2.0; bundled LICENSE and NOTICE).
- Interactive muscle-group training heatmaps in Progress, switching between primary hard sets and volume for the selected period and filters. Touch, pointer and keyboard selection reveal precise credited metrics.
- Training-plan exercise previews distinguish catalog primary muscles from secondary muscles, with an explicit unavailable classification for unknown exercises.
- Exact values table, unclassified/Unknown analytics bucket and relative legend retain transparency.

## Analytics behavior
A working set is attributed once to its primary muscle group; credited secondary contribution is displayed separately (default 0.5 per hard set). Warmups and incomplete sets are not counted as hard sets. Valid drop sets add volume, not hard sets. The pictures are **not** a measurement of muscle activation, recovery or growth.

## Privacy, compatibility and offline
No cloud account or synchronization is introduced. Existing IndexedDB snapshots, atomic saves and optimistic revision checks stay intact. App JSON exports remain **backup format v4** with prior-version import compatibility. Service worker bundles the anatomy assets for offline operation and uses a content-derived shell revision. Before installing an update, export a fresh JSON backup from Data.
