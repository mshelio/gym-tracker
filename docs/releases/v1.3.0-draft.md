# Gym Tracker v1.3.0 — final release candidate notes

**Status: prepared for review, NOT tagged or published.** The final tag must point to the exact reviewed main commit after this documentation PR is merged and checks are green.

## What's new
- **Interactive anatomical muscle maps.** Detailed front and back SVG anatomy with 89 anatomical regions adapted from [vulovix/body-muscles](https://github.com/vulovix/body-muscles) under Apache-2.0 (LICENSE and NOTICE bundled).
- **Training workload heatmaps.** Progress displays relative **primary hard sets** or **primary volume**, using existing date, workout and exercise filters. Select muscles via touch, mouse or keyboard, or use the accessible exact-value table.
- **Selected-muscle drilldown.** Inspect primary hard sets and volume, separately credited secondary totals, and a contributing-exercise breakdown for the current filtered selection.
- **Exercise previews.** Expand **Muscles worked** in Train to view anatomical primary and secondary targets for recognized exercises. Unknown exercises are explicitly unclassified.
- **Accessibility.** Improved keyboard focus retention, high-contrast outlines, screen-reader selection guidance, readable table alternatives and mobile touch access.

## Additional mobile-first improvements since the original candidate
- **Five-tab navigation:** Home, Train, Progress, Plan and More; History is under Progress and backup management under More (PR #112).
- **Focused workout logging:** Simplified Train presentation, progressive disclosure of exercise details, and accessible rest-timer controls (PR #113).
- **More useful Home, Progress, Plan and More views:** Clearer entry points, focused analytics links, schedule management and data settings (PRs #117–#119).
- **Keyboard and screen-reader improvements:** Skip navigation, mobile touch targets, dialog Escape/focus handling, validation announcements and clearer two-step deletion confirmations (PRs #120–#124).
- **Cross-browser coverage:** Pinned Playwright dependencies and expanded required mobile WebKit checks for redesigned navigation and accessibility flows (PRs #114, #116 and #125).

## How numbers are calculated
Primary working hard sets are attributed once. Secondary hard sets and volume are shown **separately** with the existing default 0.5 credit; they are not combined with primary totals. Warm-up and incomplete sets are excluded; qualifying drop sets add volume but not hard-set count. Conversion between kg and lb, historical session edits, and filtered sessions reuse the established analytics engine. This is a workload illustration, **not** a measure of muscle activation, growth, recovery or medical assessment.

## Data, privacy and offline
- The app is **local-first**, without an account or cloud synchronization. Data is stored in IndexedDB with atomic saves and revision conflict handling.
- JSON backup exports remain **version 4**, with older-version imports supported; no persistence migration was introduced by v1.3.0.
- The detailed anatomy module is included in the versioned offline app shell; updating the PWA does not require clearing site data.
- **Before upgrading, export a fresh JSON backup from Data.** Browser site-data deletion can permanently remove the local workout history.
